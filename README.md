# SmartExp Backend

Backend service for SmartExp – an AI-powered expense tracking application.  
Built using FastAPI, this backend handles authentication, expense management, chatbot processing, and financial analytics.

---

## 🚀 Features

- JWT-based user authentication (login/signup)
- Expense management with categorization
- Budget tracking and financial insights
- AI-powered chatbot for natural language expense input
- Financial health score and analytics dashboard
- RESTful API architecture
- Database migrations using Alembic

---

## 🛠 Tech Stack

- **Backend Framework:** FastAPI
- **Database:** PostgreSQL
- **ORM:** SQLAlchemy
- **Authentication:** JWT (JSON Web Tokens)
- **Migrations:** Alembic
- **Machine Learning:** TF-IDF, Logistic Regression
- **Other Tools:** Uvicorn, Pydantic
